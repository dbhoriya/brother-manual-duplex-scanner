# Changelog

## Unreleased

First public source package:

- Whole-stack single-sided and manual duplex scanning for Brother/SANE scanners.
- One-flip reverse-back interleaving and partial-pass recovery.
- Fresh empty workspace on every launch; saved projects reopen only on request.
- Local projects, PDF export and previews, crop/rotate/delete/undo.
- Scanner selection, custom backend profiles and diagnostic option discovery.
- A4-default paper sizes, light/dark themes and simple preferences.
- BS page-flip icon and Deepak Bhoriya author credit.
- Installation and troubleshooting documentation, tests and Linux CI.

Hardware verification and current limitations are listed in README.md.
